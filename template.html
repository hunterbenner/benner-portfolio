Master Template

This page is the master template for my portfolio. All five site pages started as a copy of this file, so the structure you see here is the structure of the whole site.

What every page shares

  • A head with the charset, viewport, and description meta tags, the two Google Fonts, the shared stylesheet, and the HB favicon.
  • A skip link as the first element, so keyboard users can jump straight to the main content.
  • A header with my name linked back to the home page, and the five-link navigation menu.
  • One main region with the page's own h1 inside it.
  • A footer with my copyright line, GitHub and email links, and links to the course documents.

How I start a new page from it

  1. Copy this file and rename it, all lowercase with no spaces.
  2. Update the title, the description meta tag, and the comment block at the top.
  3. Move aria-current="page" to the matching navigation link so the red underline marks the right page.
  4. Replace this documentation with the page's own heading and content.

Keeping every page on one template is why the site only needs a single stylesheet: the shared parts are styled once, and each page only adds the rules for its own content.
